# FraudGuard - Frontend + Backend (connected)

frontend/  React app   (.env already points to http://localhost:8000)
backend/   Django API  (POST /api/scan/)

## Run (open TWO terminals)
Terminal 1:  start-backend.bat   (Mac/Linux: ./start-backend.sh)   -> http://localhost:8000
Terminal 2:  start-frontend.bat  (Mac/Linux: ./start-frontend.sh)  -> open the URL it prints

Then open the Scanner page and scan a URL.
