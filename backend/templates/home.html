System Architecture & PDF Review Modules

6 Pipeline Modules
📦 1. Data Collection
scanner/pipeline/data_collection.py

Loads raw phishing datasets (PhiUSIIL URL dataset) and exports stored scans from SQLite database.

⚙️ 2. Preprocessing
scanner/pipeline/preprocessing.py

Removes duplicates and invalid URLs, performs median imputation for missing values, and scales features.

🔬 3. Feature Extraction
scanner/pipeline/feature_extraction.py

Extracts 14 core lexical URL features plus offline-safe WHOIS age, DNS status, and redirect hops.

🤖 4. Model Building
scanner/pipeline/model_building.py

Sklearn Pipeline (Imputer → Scaler → Random Forest) benchmarked against a Logistic Regression baseline.

🎯 5. Prediction Engine
scanner/model.py

Classifies websites into Legitimate, Suspicious, or Fraudulent with an actionable 0-100 risk score.

🚨 6. Alerts & Reports
scanner/pipeline/alerts.py & reports.py

Generates automated security warnings, safe-browsing tips, RFC CSV audit logs, and printable review reports.
